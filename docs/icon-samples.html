Dialarr icons

Five directions for the app icon, in the colours the console already wears — deep purple field, orange border, amber signal. Each one is drawn as an SVG so it stays sharp at 16 pixels in a browser tab and at 512 in a store listing. Nothing here is committed yet.

1 — THE DIAL

The name is the dial, so the dial is the mark: a knob with a pointer and four ticks. The simplest of the five, and the one that survives being 16 pixels wide.

2 — THE SET

A television with the picture on: a rounded screen, three scanlines, a stand. Reads as "TV" before it reads as anything else, which is the point.

3 — THE SIGNAL

A tuning wave across the middle, with the lock point marked. It is the same squiggle as the tuning screen on the TV page, so the icon and the product say the same thing.

4 — THE GUIDE

The programme guide as a mark: nine blocks, one row picked out in amber and underlined. It is the grid every viewer looks at, and the one piece of the TV page that is purely Dialarr.

5 — RABBIT EARS

A set with its antennae out and a signal inside it. The warmest of the five and the one that says "old television" fastest, at the cost of a busier shape at small sizes.

Each mark is a flat SVG with no fonts and no gradients, so it can be exported at any size and dropped into the tab, the README, the GitHub avatar and the store listing without redrawing. The small sizes above are the honest test — if a shape turns to mush at 16, it is not the right one.
