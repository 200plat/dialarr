BACKUP & MOVE

this site backs itself up automatically — daily, and right before every import — keeping about 7 days under data/backups. export grabs everything except the videos themselves — channels, schedules, shows, users, settings. on the new machine, drop the videos in the same places and import this file.

THIS BOX

FLAGS — FILES THAT WON'T PLAY

every file the cache has given up on, across every channel. a file is flagged when it can't be read (missing, corrupt, or the archive has taken it down) or when it is taller than the skip limit. rescan measures it again — good if it has finished downloading. replace points the episode at another file. remove takes it out of the show.

REMOVED

what has been taken out, and why it went.

TRANSCODE (local mkv/avi → mp4)

browsers can't play mkv/avi, so each local source is converted once to a cached mp4 and streamed to everyone. only the next few episodes of each channel are pre-converted (look-ahead), and the oldest cached files are dropped when the size limit is hit. sources taller than the skip limit (e.g. 4K) are left alone and flagged.
